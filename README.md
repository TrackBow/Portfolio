# Portfolio Professionnel - Thibault Cottel

Portfolio développé avec React et Tailwind CSS, présentant mon parcours d'ingénieur diplômé de l'INSA Hauts-de-France (spécialité Audiovisuel et Multimédia) ainsi que mes projets en développement logiciel, intelligence artificielle et traitement du signal.

## 🚀 Fonctionnalités
- **Accueil** : Présentation, biographie, lien direct vers les plaquettes de formation (prépa et cycle ingénieur).
- **Compétences** : Grille structurée par catégories (Langages, IA, Web, Signal, Soft Skills).
- **Projets** : Liste de mes réalisations techniques avec accès aux dépôts GitHub et rapports de stage.
- **Contact** : Liens directs vers mes réseaux professionnels, e-mail et téléchargement de mon CV.

## 🛠️ Stack Technique
- **Front-end** : React, Vite, TypeScript / JavaScript
- **Styling** : Tailwind CSS
- **Outils** : Git / GitHub
